## What NOT to Try

- Every edit to a tracked markdown source file (even a one-line append) requires a follow-up
  `bash .claude/scripts/generate-context-line-counts.sh --write` before the doc-lint gate will
  pass, because `check-extension-docs.sh` Rule R checks the index's declared `line_count` against
  the live `wc -l`. Budget this step after every file edit in Phase 3 (which touches 14 files),
  not just once at the end.
- A foreground `bash ... verify-deploy.sh ...` call, even wrapped in `timeout N`, is auto-
  backgrounded by the harness once it runs past ~120s (the Bash tool's own default timeout
  parameter, distinct from the inner `timeout N`). Recovered both times by polling the redirected
  log file directly (`grep` for a completion marker in a loop) rather than using `run_in_background`
  or `Monitor`, and without ending the turn to await a notification. For Phase 4's unscoped full
  gate run (expected to take longest), raise the Bash tool's own `timeout` parameter to something
  like 600000 up front rather than relying on getting auto-backgrounded again.
