## Key Decisions Made

- Extraction helper anchors to the FIRST bracket pair via a `[^[]*` prefix, not a greedy `.*`
  prefix. The original greedy form (`.*\[\([^]]*\)\].*`) matches the LAST bracket pair on a line
  with two pairs, which disagreed with the mutating sed (which only ever rewrites the first
  pair) and produced a false post-mutation verification failure. This was caught by hand-testing
  the two-bracket-pair fixture and fixed before commit — it is not something the plan called out
  as a risk explicitly for the extraction helper, only for the mutation, so watch for it if
  Phase 2's fixture suite is authored independently.

## Deviations from Plan

## What NOT to Try

- Do not use a greedy `.*\[...\].*` pattern for extracting the status token — it silently
  captures the wrong bracket pair on any line with two or more bracket pairs.
