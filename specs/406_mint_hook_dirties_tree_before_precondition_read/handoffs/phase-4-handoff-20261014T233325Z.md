## What NOT to Try

- Do not write test fixture content into the tracked events log before the fixture's own
  specs directory exists -- the push-fixture helpers do not create it ahead of time, and a
  silent redirection failure (visible only as stderr noise, since these suites use
  `set -uo pipefail` without `-e`) leaves the file missing, which then makes a following
  multi-path `git add` (naming that file alongside other explicit paths) fail its WHOLE add
  atomically in at least one observed git version, leaving the entire deployed-shaped scaffold
  uncommitted too. Create the parent directory first.
- Do not check a buffer path returned by a subshelled accessor call against the bare relative
  string it returns -- that accessor is CWD-relative, so a file-existence test outside the
  subshell must prefix the result with the fixture's own absolute repo path.
