## What NOT to Try

- Do not use two SEPARATELY-BUILT `build_path_without_sapience()` scratch directories across a
  before/after pair of hook invocations meant to isolate "sapience absent" as the only
  variable -- each call creates a fresh scratch dir, so `command -v python3` resolves to a
  DIFFERENT absolute symlink path each time (since `setup-sapience-mcp.sh`'s
  `resolve_interpreter()` always re-resolves fresh for a project-scoped entry; it only inherits
  from the unrelated TOP-LEVEL global entry). This makes the writer spuriously judge an
  unchanged project entry as "diverged" and rewrite it. Use ONE shared scratch directory and
  add/remove only the `sapience` file from it between the two invocations
  (`install_sapience_stub_into` helper) so every OTHER resolved binary's path stays identical.
