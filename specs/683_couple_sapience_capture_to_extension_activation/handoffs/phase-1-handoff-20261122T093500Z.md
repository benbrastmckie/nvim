## What NOT to Try

- Do not simulate "no sapience binary" by narrowing `PATH` to `/usr/bin:/bin` -- this machine
  (NixOS) has no `bash` there and the test hangs the harness with "command not found". Use the
  new `build_path_without_sapience()` helper instead (symlinks everything on the ambient `PATH`
  except any file literally named `sapience` into one scratch dir).
- Do not use `grep -c ... || echo 0` to count stub invocations -- `grep -c` already prints `0`
  on a no-match AND exits nonzero, so the `||` fallback double-prints it as `"0\n0"`. Capture
  `grep -c`'s stdout into a variable first, independent of its exit status.
