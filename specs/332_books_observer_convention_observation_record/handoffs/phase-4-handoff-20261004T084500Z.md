## Key Decisions Made

- Refactored the Phase 3 inline body into `observe_run_core()`, a function parameterized by
  `is_backfill`, called once by live mode and once per task directory by `--backfill`/`--all` —
  avoids duplicating the join/compute logic between the two modes.
- Amended `observation-record.md`'s schema (committed alongside this phase) to wrap
  `book_requires_churn`, `validated_by_promotions`, `verification_tiers`, `certifier_outcomes`,
  and `snapshot_delta` with a per-group `source: collected|backfilled` marker, since Phase 3's
  prose had specified this (D2) without the script actually attaching it anywhere.
- `figure_provenance` on a backfilled record maps only the books-specific figures this script
  itself derives from git history (`book_requires_churn`, `validated_by_promotions`) to
  `"derived"` — the generic join half is pass-through aggregation of already-written files,
  identical in live and backfill mode, so it carries no figure_provenance entry.
- `--backfill` task-directory resolution is a plain glob over `specs/*_*`, deliberately not via
  `scripts/lib/task-lookup-lib.sh`, since this script must run standalone in an arbitrary
  consuming repository.
