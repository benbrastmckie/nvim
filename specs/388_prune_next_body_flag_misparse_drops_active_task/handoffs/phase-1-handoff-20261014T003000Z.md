## Key Decisions Made

- Segmented on the first whitespace-preceded `-` (via `match(tasklist, /[ \t]+-/)`), not on the
  first run of whitespace, to avoid mis-splitting the grammar-legal `716, 714 --hard` (intra-list
  space) — this was flagged in the plan as a deliberate narrowing of research Recommendation 1.
- `flags` is derived as `substr(tasklist, RSTART + RLENGTH - 1)` so it begins at the first `-`
  (not the leading whitespace), and is re-spliced with an explicit single leading space via a
  `tail` variable (`(flags != "" ? " " flags : "") rationale`).
- The fail-safe guard checks every post-split id token against `^[0-9]+$` before computing
  `kept`/`joined`; on any non-numeric token it prints the original line unchanged and emits
  `WARNING: prune_next_body: unparseable task id '<token>'; Run line left unchanged` to stderr.
