## What NOT to Try

- Do not embed a literal `'` character directly inside an awk program that is itself delimited
  by bash single quotes (`awk '...'`) — it silently breaks the shell's quoting rather than
  erroring. Either escape it with the `'"'"'` idiom or avoid embedding single quotes in that
  context entirely (as done here, via square brackets).
- Do not mutate `write_roadmap_fixture`/`write_stage_vocabulary_fixture` to add new Run lines —
  both are shared by other case groups; add a dedicated fixture-writer function instead.
