## What NOT to Try

- Do not actually execute `:Sf1` in a headless `nvim --headless -c "Sf1" -c "qa"` smoke check:
  it spawns a real `sf1_proxy.py` -> real `sf1` process tree that blocks on network/token input
  and leaves orphaned processes behind when the harness times out and SIGTERMs nvim (the proxy's
  forked grandchild is not reaped by that kill). Verify command registration via
  `nvim_get_commands` instead.
