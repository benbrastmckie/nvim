## Deviations from Plan

- **Fixed a latent bug, not a deviation from any named task, but worth flagging**:
  `rsp_move_commit_onto_new_parent` returned its result tree via stdout captured in `"$(...)"`
  at all three call sites (cut's `rsp_cut_execute`, and this phase's two new call sites). A
  refusal's `exit 48` inside that command-substitution subshell only terminates the subshell,
  silently swallowing the refusal -- never triggered by the existing 38-case cut suite (no
  conflicting-cut case exists), but immediately triggered by this phase's own required
  "conflicting descendant refuses 48" case. Fixed by switching the function to set a global
  `RSP_MOVE_RESULT_TREE` and calling it as a plain statement everywhere, matching the file's own
  documented resolver convention (see the comment above `RSP_INTEGRATION_BRANCH=""` near the top
  of the file). Logged via `issue-record.sh`. This is a strict bugfix of the shared primitive's
  calling convention, not a change to its git plumbing; the 38 pre-existing cut cases still pass
  unmodified.
