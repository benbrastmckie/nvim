  to be a branch-shaped ref, not a tag, for restack specifically (the existing PD1 resolver
  itself accepts any ref; this is a restack-only assumption documented via the new
  `restack_fixture_repo` test helper, which declares `review_base` as a dedicated branch).
- The local/remote-tracking divergence test (exit 54) is `! git merge-base --is-ancestor
  <local> <remote>`: the ordinary "remote moved ahead" case (local is an ancestor of remote, or
  equal) never refuses; only a local commit the remote-tracking ref does not have as an
  ancestor (local ahead, or a true fork) refuses.
