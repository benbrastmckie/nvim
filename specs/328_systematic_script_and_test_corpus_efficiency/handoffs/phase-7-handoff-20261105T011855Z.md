## What NOT to Try

- Do not trust a loose substring match ("does this file mention lib/common.sh anywhere") to
  decide whether a suite already sources the harness. 9 of 48 files in this tranche referenced
  `lib/common.sh` only as a fixture-copy source (`cp ... lib/common.sh`) or a dependency-existence
  check, never as an actual `source`/`.` statement in the suite's own shell. Removing local
  pass()/fail()/info() without inserting the real source line in those 9 left every renamed
  `common_test_*` call undefined; under `set -uo pipefail` (no `set -e`) this fails silently —
  the suite still exits 0 but records 0 assertions instead of crashing loudly. Caught only by
  the mandatory before/after output diff, not by `bash -n`. Require detection of an actual
  top-level `source`/`.` statement naming `lib/common.sh` before skipping the insertion.
