## What NOT to Try

- Do not treat a green `verify-touched.sh` run as evidence for un-deployed source edits: with
  root `.` it runs `./.claude/scripts/tests/run-all.sh` (the stale deployed copies), and
  `--tree-root agent-system/extensions/core` is refused ("no declared root resolved").
- Do not run a long suite set as one foreground Bash call: the harness backgrounds any call at
  180 s regardless of the `timeout` parameter, and `run-all.sh --jobs auto` buffers all output
  until the end, so an inner `timeout` below the real runtime kills it with no result.
- Do not leave `CORE_TEST_SUBJECT_MODE=source-store` set when running `test-common-lib.sh`; it
  asserts the unset default and fails under the override.
