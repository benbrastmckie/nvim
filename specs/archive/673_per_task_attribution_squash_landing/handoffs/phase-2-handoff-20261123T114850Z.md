## Key Decisions Made
- Diagnostics go to standard error; standard output carries only `--print-body`.
- A task whose commits touch only the state territory has an empty path set; its end commit is its last attributed commit and any recorded proof with an empty path set makes a re-run a no-op.
- `--check` takes no commit mutex.
- A task entry with no `created` is bounded by the oldest `admitted_at` among the batch records listing it (30 of 137 active tasks have no `created`).
- The proof's `phases` elements are `{phase, name}`; `source_store_commits` is read from the return metadata's `source_store_commits` array when present.

## What NOT to Try
- `verify-touched.sh` for a phase that adds a new suite: it runs the deployed runner, which rejects the undeployed suite name. Run the resolved `--only` list through `agent-system/extensions/core/scripts/tests/run-all.sh` instead, detached with a PID waiter (about 15 minutes for 47 suites).
- A foreground Bash call longer than 180 seconds: the harness backgrounds it.
