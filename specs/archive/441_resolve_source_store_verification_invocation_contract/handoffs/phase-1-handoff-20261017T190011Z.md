## Key Decisions Made
- The opt-in acceptance test requires `agent-system/extensions` to exist directly under the
  git-toplevel candidate, matching the same structural requirement an opted-in caller's own
  `EXT_DIR` default already uses.
- On acceptance, the opt-in variable itself is unset alongside the guard's own temporaries, so a
  caller's environment is not left carrying a stale opt-in flag.
