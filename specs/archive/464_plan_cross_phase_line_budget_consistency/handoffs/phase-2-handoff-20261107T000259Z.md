**Key Decisions Made**: Unit-word matching normalizes to a singular stem (strip trailing "s") so
"lines" (plural, in Scope Hypothesis prose) and "line" (singular, hyphen-joined in ceiling
prose like "1500-line limit") are recognized as the same unit. Ceiling citation requires a
digit, a ceiling-indicating word, and the unit stem all on the SAME line (deliberately strict,
to hold down false positives); conformance assertion requires the stays/remains+under/within/
below phrase and the unit stem anywhere in the document (looser, since it is usually a
sentence away from the ceiling citation).

**What NOT to Try**: Don't use `grep -n` in a pipeline whose downstream step extracts the first
digit from the matched text — the line-number prefix itself contains a digit and will be
mistakenly picked up as the real value (hit this exact bug once; fixed by dropping `-n`).
