## Overview

The live `~/.claude.json` registered `lean-lsp` against a hand-authored wrapper script inside a
project's disposable `.claude/scripts/` deploy tree; that file no longer existed, producing a
silent ENOENT at every session spawn for every repository relying on the global entry. This
implementation repaired the two source-store scripts (`setup-lean-mcp.sh`,
`verify-lean-mcp.sh`) so they can actually detect and repair this class of drift, recorded the
durable invariant that a `command` path must never resolve inside any repository's own
`.claude/` tree, reconciled the live global config, retired cslib's orphaned wrapper and its
project-scoped override, and proved the fix with an observed lean-lsp spawn plus a real MCP
tool call from fresh sessions in both `~/Projects/BimodalLogic` and `~/Projects/cslib`.

## What Changed

  alongside `lakefile.lean` (both the CWD and git-root tests); replaced the "already configured"

## Decisions

- Whole-entry comparison/repair (never per-field) in `setup-lean-mcp.sh`'s idempotency check,
  so command/args drift can never again hide behind a matching project path.
- Command/args checks in `verify-lean-mcp.sh` promoted to hard failures — an unspawnable
  registration is a more serious condition than a stale path, and the companion drift-detection
  task (not this one) needs a verifier that actually fails on a dead command to have anything to
  detect.
- Single global user-scope `lean-lsp` entry retained (Option A from the plan's recorded
  `user_decision`, not re-litigated here since the plan already resolved it): switching which
  Lean project `lean-lsp` indexes requires re-running `setup-lean-mcp.sh` from the target
  project. cslib's project-scoped override was removed rather than formalized as a second
  sanctioned mechanism.
- cslib's orphaned wrapper was archived (md5sum-verified) before deletion rather than blind-
  deleted, and its project-scoped override was removed only after Phase 4 confirmed the global
  entry was live and correct — cslib was never left without a working registration.
