## Decisions

- Where the old Stage/Stage-MT split genuinely collapsed into one current call site (e.g. the
  three former handoff-reading sites all now going through `orchestrate-cycle-postflight.sh`'s
  single Move 3 call), the citation was rewritten as "the now-single Move 3 call site (formerly
  base Stage 5, base Stage MT-4, and hard Stage 5)" rather than a bare anchor swap — this is a
  structural fact change (three sites -> one), not merely a renumbering, and leaving the old
  "three call sites" framing unedited would have made the citation actively false.
- `research-flow-example.md`'s worked trace was rewritten end-to-end (per the plan's own
  Decision) rather than reframed as historical, since the file's own opening sentence promises a
  trace "through the current architecture."
- The `mode-gated-section-loading.md` paired-bash-comment-convention citation was reframed as
  pure historical precedent rather than retargeted to a live example, because no live example of
  that convention exists anywhere in the current `SKILL.md` or the core extension tree (confirmed
  by a fresh `grep -rln -- "name:begin ---"` at implementation time, consistent with the Phase 1
  resolution).
- Two bare "Stage 5a" occurrences in `orchestrator-runtime-files.md` were fixed even though the
  plan's scoped grep pattern (`Stage [0-8]\b`) technically cannot match them (a digit-letter
  compound like "5a" defeats the `\b` word boundary) — they sat on lines already being edited for
  an adjacent match and had an unambiguous mapping-table entry, so fixing them served the
  acceptance criteria's actual intent without expanding scope.
