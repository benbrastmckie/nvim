**What NOT to Try**: Do not name an awk scalar variable `close` (or other awk builtins like
`index`, `length`, `substr` used as plain identifiers) -- awk's parser treats them as the
builtin call form and a bare assignment/use as a variable is a syntax error in this gawk/mawk
environment.
