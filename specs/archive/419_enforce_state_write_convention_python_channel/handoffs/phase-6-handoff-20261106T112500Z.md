**What NOT to Try**: Do not assume a newly-`Write`-tool-created shell script carries the
executable bit -- the Write tool does not set it, and `deploy-headless.sh`'s copy step
apparently preserves whatever bit the source-store file already has rather than normalizing it.
Any new `scripts/tests/*.sh` suite file needs an explicit `chmod +x` in the source store before
its first deploy, or `run-all.sh` will SKIP it (loudly, but still skip it) rather than running it.
