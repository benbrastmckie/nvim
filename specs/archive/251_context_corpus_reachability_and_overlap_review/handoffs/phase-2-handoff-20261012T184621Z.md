## Current State
Phase 2 COMPLETED. context-reachability.sh now computes all three non-short-circuiting reference
styles (filename/directory/index), the inbound-reference census, reachable/reachable_styles, and
zero_reference_finding, with --check wired to the per-file table and non-zero exit on a finding.
Live run against the real repo: candidate_count=591, zero_reference_count=0. All 39
present+founder template files report reachable:true with directory among their styles.

## Key Decisions Made
- Style 1 (filename) scope is the WHOLE source store (including other context/ files as valid
  referrers) -- confirmed correct by the plan's own stated expectation that founder's basename
  mentions inside slidev-deck-template.md (itself a context/ file) count.
- Style 2 (directory) scope is OUTSIDE context/ only, and must test every contiguous (i,k)
  sub-range of the directory-component list, not only leaf-ending suffixes -- see Deviations.
- inbound_references reuses style 1's exact computation (documented in the header as
  intentional, not redundant-by-oversight).

## Deviations from Plan
- None in scope/fields delivered. Two approaches were tried and corrected before landing (see
  progress file's approaches_tried): the naive per-candidate grep design (too slow, replaced with
  a two-pass batched design) and leaf-only directory suffixes (missed founder's generic
  top-level directory reference, replaced with full contiguous sub-range enumeration).

## What NOT to Try
- Per-candidate  invocations for style 1/style 2 on this corpus size -- confirmed over
  5 minutes wall-clock. Always batch into one multi-pattern grep pass per style.
- Directory-suffix generation anchored only at the leaf -- confirmed to miss ancestor-only
  (non-per-subdirectory) directory references like founder's bare "deck/contents/".

## Critical Context
- Runtime for a full live-tree default-mode run is ~40s. Phase 4's reproducibility case (two
  consecutive runs) and Phase 8's full gate set should budget accordingly with the bounded-wait
  idiom (Bash tool timeout parameter, not the default 120000ms).
