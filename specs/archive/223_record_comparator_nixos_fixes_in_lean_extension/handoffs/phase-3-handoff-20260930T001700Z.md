- `git_remote_preflight()` runs as its own main-flow step (`clean_room_setup;
  resolve_toolchain; git_remote_preflight; synth_config; run_sandboxed; classify_verdict`),
  not folded into `clean_room_setup()` or `run_sandboxed()`.
- Outer landrun reuses `$LANDRUN_PATH` directly (no separate override var for the outer layer) --
  it is already a hard requirement via `fail_unavailable` earlier, so the "non-fatal absence"
  branch in `run_sandboxed()` is defensive belt-and-suspenders, not an expected-to-fire path.
- `HOME` is now forwarded (both inner `-E` and outer `--env`) -- the reference explicitly does
  this and landrun drops everything not named; it was not previously forwarded pre-Phase-3
  because no landrun wrap existed for it to be dropped by.
