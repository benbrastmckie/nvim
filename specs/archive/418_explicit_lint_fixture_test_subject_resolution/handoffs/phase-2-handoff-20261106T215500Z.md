**Key Decisions Made**:
- **Corpus-collection bug found and fixed during this phase**: the lint initially used
  `lint_corpus_scan_collect_files`'s shared-corpus-reuse optimization with pattern `'*.sh'`.
  Under a bare invocation this degrades safely to a scoped `find`, but under `verify-deploy.sh`
  (which exports `GATE_SHARED_CORPUS_FILE`/`GATE_SHARED_CORPUS_ROOT`), the shared-corpus path
  matches the pattern via `[[ == ]]` globbing against the WHOLE repo-wide corpus -- `*` spans
  directory separators freely, so `'*.sh'` matched every `.sh` file in the tree, not just
  `scripts/tests/*.sh`, producing false `[VIOLATION]` rows from unrelated files and failing gate
  27 only when run through `verify-deploy.sh`. Fixed by replacing the call with an unconditional
  direct `find` scoped to the explicit scan path, bypassing the shared-corpus branch entirely
  (this corpus is small and flat, so the optimization's cost saving does not apply anyway).
