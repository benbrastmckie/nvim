## Key Decisions Made

- Discharge is gated on the WHOLE run's `gate_exit_code`, not per-task: an owed path is owed
  against "the complete gate set passing," and a failure anywhere (even attributed to a
  different task) means that obligation is not yet met for anyone.
- The owed-sweep logic lives inline in `orchestrate-batch-gate.sh` rather than a separate script,
  because this stage already iterates `.task_numbers` once for finding attribution and is the
  one place a "this run was clean" verdict exists at all.
