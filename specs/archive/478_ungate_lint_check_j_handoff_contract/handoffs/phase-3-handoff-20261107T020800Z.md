without checking whether it collides with `core/agents/`'s OTHER two
`CHECK_J_EXCLUDED_RELATIVE_PATHS` entries (code-reviewer-agent.md, meta-builder-agent.md) once
that directory exists in a given fixture tree -- the per-extension-agents-directory sweep guard
evaluates ALL entries under an extension once ANY of its files exist there, not just the one a
test author intended to exercise.

restored-content-gate copy, or a dump of raw `$out`), the copy's own `SCRIPT_DIR=` line must be

location) -- both suites source `$SCRIPT_DIR/../lib/common.sh` and several canonical fragment
files relative to `SCRIPT_DIR`, which resolve incorrectly if the copy lives outside the real
repo tree.
