## What NOT to Try

- Do not build a Y-series fixture by committing a NEW file in the SAME repo AFTER
  `build_repo_cached_untracked` has already run `git rm -r --cached sub` -- an unscoped
  `git commit` there commits the WHOLE index, prematurely landing the pending untracking before
  the case under test ever invokes the script (hit this exact bug building Y6's first draft; see
  `approaches_tried` in `progress/phase-3-progress.json`). Any fixture needing a second tracked
  file alongside `sub/` must track it in the SAME initial commit, before the `rm --cached` step.
