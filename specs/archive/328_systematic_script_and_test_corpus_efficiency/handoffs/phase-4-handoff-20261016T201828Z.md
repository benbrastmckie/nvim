  `tests/test-test-harness-lib.sh`) in favor of extending the already-existing `common.sh` and

  would have been a net-addition duplicate of exactly the kind this task's acceptance criterion
  exists to catch. Full reasoning recorded in the plan's Phase 4 Deviation note.

  `WORKDIR="$(common_test_workdir_init)"` — command substitution's own subshell triggers the
  function's EXIT trap immediately, deleting the directory before the outer assignment can see
  it. Documented in the function's own header comment and in the required-structural-model
  usage example.
