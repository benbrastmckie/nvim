## Key Decisions Made

- Color suppression (`NO_COLOR`/`SF1_NO_COLOR`/`SF1_COLOR`) is read by the caller (Phase 2's
  `main()`), not inside `SeparatorFilter` itself: the constructor takes a resolved `color: bool`
  so the filter stays free of environment/global-state reads, matching the "no I/O, no global
  state" requirement.
- B3 (fresh-prompt) detection buffers at most 128 bytes while a line could still become a
  prompt match; everything else streams through immediately with no buffering, so a long
  streamed answer line is never held back waiting on a match decision.
- The transient-indicator toggle and the B1 marker scan both run as small bounded rolling
  windows on every byte, independent of the prompt-buffering state, so the three mechanisms
  cannot interfere with each other.

## What NOT to Try

- Do not buffer whole lines waiting for a `\n` to decide B1/B3 -- this was the first design
  considered and rejected because it would defeat sf1's real-time streaming UX for long answer
  lines. The bounded-buffer-for-prompt-only design is the one implemented.
