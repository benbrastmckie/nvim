## What NOT to Try

- Do not invoke a suite via a direct `bash <suite>.sh` or `run-all.sh --only` from any working
  directory other than the repository root. `test-gate-out-repair-reporting.sh`'s Case 3 calls
  `skill_validate_task_artifacts` directly (no `cd`), which internally resolves
  `.claude/scripts/validate-artifact.sh` as a CWD-relative path — wrong from `scripts/tests/`,
  correct from the repository root. A wrong-CWD invocation produces 6 deterministic false
  failures that look exactly like a real regression.
