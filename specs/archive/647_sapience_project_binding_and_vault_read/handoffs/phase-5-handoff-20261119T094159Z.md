## Key Decisions Made
- Partial-hunk staging technique for a shared file carrying a foreign uncommitted change: isolate
  this task's own hunks into a sub-patch, `git apply --cached` it, temporarily swap the working
  tree to match the staged content so the commit wrapper's own `git add` is a no-op, commit, then
  restore the working tree to its prior (foreign-hunk-included) state.

## Deviations from Plan

## What NOT to Try
- Do not pass a shared file carrying a foreign uncommitted hunk directly to `git-commit-phase.sh`/
  `git-commit-scoped.sh` as a pathspec when only some of that file's hunks are this task's own --
  it will re-stage the whole working-tree diff.
