## Key Decisions Made

- The intent snapshot enumerates via the UNION of `git ls-files`, `git diff --name-only HEAD`,
  and `git ls-files --others --exclude-standard`, each restricted to the full
  `filtered_pathspecs` array, run **before** `git add`. This timing is load-bearing — the same
  enumeration run after `git add` loses the vacated half of a rename (confirmed by direct probe);
  running it pre-add correctly picks up both halves via the different listing commands.
- V8's comparison logic is placed textually *before* the V6 gate's own `exit 4`, not strictly
  after it as the task bullet's literal wording suggested — otherwise V6's exit would suppress
  V8's own diagnostic whenever both could apply to one invocation. The actual exit-code decision
  (preserve 1/4, or introduce 5) is still made last, after both gates run. Recorded as a Plan
  Deviation (altered, not skipped).
- Associative array `v8_intent` (bash `declare -A`) used for path -> intended-hash/"absent"
  mapping; guarded by `${#v8_intent[@]}` before iteration per the script's established `set -u`
  pattern.
