## Key Decisions Made

- **Deploying mid-task, ahead of Phase 5**: `deploy-headless.sh` was run during Phase 2 (not
  deferred entirely to Phase 5) because the deployed `.claude/scripts/update-plan-status.sh` was
  stale relative to Phase 1's source-store fix, and the Phase 2 test suite's deploy-tree-first
  candidate resolution would otherwise have silently tested stale behavior. Deploying is
  idempotent, so this does not conflict with Phase 5's own "redeploy and confirm" step — Phase 5
  will simply redeploy again to pick up Phases 3-4's additional changes and do the final
  acceptance walk.
- **A new script must be registered in the extension manifest to deploy at all.**
  `deploy-headless.sh` copies only files listed in the owning extension's `manifest.json`
  `provides.scripts` array. The new `tests/test-update-plan-status.sh` was invisible to
  `run-all.sh` after the first redeploy (0 occurrences in its output) until
  `"tests/test-update-plan-status.sh"` was added to
  `agent-system/extensions/core/manifest.json`'s `provides.scripts` list (placed next to
  `tests/test-update-task-status.sh`), after which a second redeploy copied it in and `run-all.sh`
  discovered and passed it. This is recorded in Phase 2's progress file `approaches_tried` as a
  failed-then-fixed approach. **This manifest edit is an additional file beyond the plan's
  originally enumerated per-phase file lists** (Phase 2 named only the new test file itself) —
  flag it explicitly when walking Phase 5's "confirm no edits landed under .claude/**" check:
  `agent-system/extensions/core/manifest.json` is a source-store file and is the correct edit
  location per `source-store-deploy-boundary.md`, so this is not a boundary violation, just an
  addition not explicitly named in the plan's Phase 2 "Files to modify" list.
- Several `deploy-headless.sh`/`verify-deploy.sh` gates (doc-lint on
  `return-metadata-file.md`/`return-meta-artifacts-template.md` index line counts,
  state-writer-boundary-lint on `test-force-phases.sh`, whole-tree orphan detection) show
