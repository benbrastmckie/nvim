## Overview

The research phase rendered the record's verdict and refuted most of its premise: `specs/CHANGE_LOG.md`
is KEPT unmodified, the `task {N}: {action}` commit convention is accepted and worked around, and no
new field, file, script, or gate is warranted. One genuine gap survived that verdict — nothing in the
artifact-format standards tells an author how to cite a decision recorded in *another* record durably,
so citations default to a bare record number that a vault operation silently invalidates. This plan
lands exactly that gap's closure: a named, advisory citation convention in the artifact-format
standards, a recognized optional `## Decisions` home for plan-time decisions, and the anti-drift
mirror in the one script whose own header comment points at these format files as its source. No new
file is created, no behavior changes, and nothing is retired.

Definition of done: the convention is stated once as a named section, pointed at from the other two
format standards, `## Decisions` is a documented recognized-optional plan section that
`validate-artifact.sh` continues not to require, and the deployed `.claude/` tree carries all of it
after a redeploy with a clean full gate run.

Two constraints shape every phase below. First, **the source store is the edit target**:
`agent-system/extensions/core/` only, never `.claude/**`, which is a disposable deploy artifact
regenerated by `deploy-headless.sh`. Second, **the added prose lands under `agent-system/**`**, where
both the no-task-number-references rule and the no-record-versioning rule apply in full — so the
convention's own worked example must cite by slug, and no added sentence may narrate this record's
draft history or use "previously"/"no longer"/"formerly" phrasing.

### Research Integration

Five of the research report's six Decisions require no implementation and are carried forward as
recorded verdicts, not work: CHANGE_LOG is kept unmodified (Decision 1), the commit convention is
accepted as-is (Decision 2), no new durable-id scheme is minted (Decision 3), `parent_task` is left
unoverloaded (Decision 4), and no mechanism lands beyond what the design itself requires (Decision 6).
This plan implements Decision 5 alone.

Two refinements to Decision 5 were settled at planning time and are recorded here with their grounds,
so a reader can disagree with the grounds rather than only the outcome:

- **`## Decisions` in plans is a *recognized optional* section, not a required one.** Decision 5's
  phrasing ("so plans gain the same mandatory home reports and summaries already have") would, taken
  literally, mean adding `Decisions` to `validate-artifact.sh`'s `PLAN_SECTIONS` array — which drives
  a hard `log_error "Missing required section"` at gate-out. Measured live: `PLAN_SECTIONS` is
  `("Overview" "Goals & Non-Goals" "Risks & Mitigations" "Implementation Phases" "Testing & Validation"
  "Artifacts & Outputs" "Rollback/Contingency")`, and no plan in the tree carries a top-level
  `## Decisions`. Promoting it would fail every existing plan at gate-out for a prose convention that
  has no mechanical reader. The recognized-optional tier is the correct landing, and it has an exact
  in-script precedent: `SUMMARY_SECTIONS_OPTIONAL=("Plan Deviations")`, a documentation-only array
  carrying `# shellcheck disable=SC2034`, deliberately never wired into `required_sections`.
- **The convention is stated once and pointed at twice, not written three times.** Decision 5 names
  the Writing Guidance of two format files plus a structural addition to a third. Triplicating the
  convention's prose creates three copies to drift apart — the precise failure the whole record is
  about. The canonical statement lands as a named section in `report-format.md`, beside
  `## Carried-Figure Discipline`, which is already a cross-artifact authoring discipline documented in
  exactly one format file and referenced by a one-line Writing Guidance bullet. The other two
  standards carry that same one-line pointer shape.

## Goals & Non-Goals

**Goals**:

- Give plan-time decisions a documented home (`## Decisions`) at the recognized-optional tier, without
  changing what `validate-artifact.sh` requires of any plan.

**Non-Goals**:
- Modifying, retiring, or writing to `specs/CHANGE_LOG.md`, or fixing any pointer to it. The verdict is
  KEEP, unmodified.
- Changing the `task {N}: {action}` commit convention, adding an epoch marker, or touching
  `rules/git-workflow.md`. The verdict is accept-and-work-around.
- Minting any new id scheme, JSON field, file format, script, or gate.
- Overloading `parent_task`, or touching `context/reference/state-management-schema.md`. The research's
  Context Extension Recommendation raised a mention there as an explicit nice-to-have for this plan to
  decide; it is declined, because a pointer from a state-schema field section to an artifact-authoring
  convention adds a fourth copy-or-pointer site for no reader the format standards do not already
  reach.
- Promoting the convention to mechanical enforcement. Its degradation risk is accepted, on the
  research's own grounds.

## Rollback/Contingency

Every change is additive — markdown prose in three existing standards and a comment-plus-unused-array
block in one script — committed one phase at a time with explicit file-list pathspecs, so reverting is
a scoped `git revert` of this record's two edit commits followed by
`timeout 540 bash .claude/scripts/deploy-headless.sh` to regenerate the deployed tree without them.
No schema, no test fixture, and no behavioral surface is involved, so a revert cannot strand partial
state.

If Phase 3's complete gate run surfaces a finding naming one of this record's four files, fix forward
in the source store and redeploy — never discard uncommitted work to reach a passing gate. If it
surfaces only pre-existing findings naming other files, report them and close; they are outside this
record's declared scope. If a rollback that would discard uncommitted work becomes genuinely
necessary, take the snapshot first per `context/contracts/recovery.md`'s rollback rung, with the task
number explicit — never the bare no-argument form, and never the reverting default as a precautionary
checkpoint.
