## Key Decisions Made

- All four checks (A/B/C/D) were implemented together in one pass in the single lint script,
  rather than incrementally across three separate phase-commits with no diff between them --
  phases 1/2/3 share the same extraction (`extract_invoked_script`), classification
  (`classify_anchor`), and normalization (`normalize_identity`) helper functions; writing them
  once correctly was more reliable than writing throwaway stubs per phase. This is recorded as a
  deviation in each of progress/phase-{1,2,3}-progress.json.
- `extract_invoked_script` uses `read -ra words <<< "$text"` (not an unquoted `for word in $text`
  loop) specifically to avoid bash pathname/glob expansion on tokens like `*"state.json"*` that
  appear verbatim in several real command strings.
- A line with no `bash ... .sh` invocation at all (an inline shell snippet, or an MCP
  `"command": "npx"`) is never reported in any form, not even under `--verbose` -- it is not a
  "candidate" by this lint's own definition. This was necessary to satisfy Phase 1's requirement
  that `root-files/settings.json`'s `_comment` field and `memory/settings-fragment.json`'s `npx`
  MCP command never appear in `--verbose` output at all.
- Fixed a `set -u` + empty-array gotcha: `"${arr[@]:-}"` on a zero-element array expands to ONE
  empty-string element (not zero elements) in this bash version, which silently inflated
  `SETTINGS_FILES` counts. Fixed by using plain `"${arr[@]}"` everywhere (safe under `set -u` for
  empty arrays, unlike the `:-` form) rather than the `:-` defaulting idiom.

## What NOT to Try

- Do not try to make Check A/B use `jq` for extraction -- the markdown fenced blocks are JSON
  *fragments*, not parseable documents, and `jq` cannot read them. The line-oriented
  `extract_invoked_script` approach is deliberate (see D3/D4 in the script header).
- Do not port `merge.lua`'s `hook_identity()` (`.claude/hooks/NAME.sh`-anchored only) into this
  lint's Check C identity notion -- D4 in the script header records this as an accepted,
  deliberate divergence, not an oversight.
