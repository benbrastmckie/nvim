## Key Decisions Made

- Classification runs as an independent filtering pass over `files_touched`, BEFORE the existing
  Containment Self-Check block, rather than being folded into that block's own `is_contained()`
  loop -- this guarantees a `SOURCE_STORE`/`OUT_OF_REPO` path can never reach the scope test
  regardless of whether `file_scope` itself is present, empty, or malformed (the classification
  loop is gated only on `files_touched` being non-empty and the library being available, not on
  `file_scope`'s own fail-open gate).
- `source_store_commits` is declared unconditionally (even `()`), so Phase 4's wiring can rely on
  it existing without a `declare -p` guard.
