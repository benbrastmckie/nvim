## What NOT to Try

- **Do not pass `agent-system/extensions/core/index-entries.json` as a bare pathspec to
  `git-commit-scoped.sh` or any `git commit`/`git add` invocation while a sibling task holds an
  unstaged edit to the same file.** `git commit -- <path>` and `git add <path>` both take the
  CURRENT WORKING-TREE content of the named path, not whatever is already staged — verified
  directly in a scratch repo this dispatch. The safe technique used here: stage only your own
  hunk via `git apply --cached <single-hunk-patch>`, temporarily overwrite the working file with
  the staged blob (`git show :path > path`) so working tree == index for that path, commit via
  the scoped script, then restore the full working-tree content (the sibling's untouched
  concurrent edits) from a backup taken BEFORE the overwrite.
- **Take the backup copy and the destructive overwrite in SEPARATE bash tool calls.** This
  dispatch nearly destroyed a sibling's 3 uncommitted hunks because a single multi-line bash call
  containing both the backup `cp` and a later `git checkout-index` was blocked ATOMICALLY by
  `guard-destructive-git.sh` before any line of that call executed — the backup never happened,
  but the later non-git overwrite line still ran as its own tool call. Recovered losslessly only
  because the destroyed content (`index-entries.json` line-count values) was 100% mechanically
  re-derivable via `generate-context-line-counts.sh --write`, not hand-authored prose. Recorded
  as an issue (`concurrency hazard`, severity `costly`) in this task's issue log.
- **Do not expect `verify-deploy.sh --only-gate 3,4` to be fully clean at Phase 2.** It will show
  exactly one `FAIL` — "deployed script content drift: scripts/lib/task-classification-lib.sh" —
  attributable to Phase 1's source-store edit (not yet redeployed), not to any Phase 2 content.
  This self-resolves at Phase 6's `deploy-headless.sh` step; do not attempt an early redeploy to
  silence it, since `deploy-headless.sh` reads the current on-disk state of the ENTIRE
  `agent-system/` tree, including any concurrent sibling's uncommitted, possibly-incomplete edits.
