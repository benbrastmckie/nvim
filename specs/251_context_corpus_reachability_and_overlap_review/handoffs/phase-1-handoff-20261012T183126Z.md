## Key Decisions Made
- git ls-files requires two glob patterns ('context/*.md' and 'context/**/*.md') since git's **
  magic never matches zero intervening segments -- a single-pattern approach silently drops
  files living directly in an extension's context/ root.
- Output field name is "files" (per dispatch wording), not "scripts".
