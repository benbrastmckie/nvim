## What NOT to Try
- Do not invoke the deployed `.claude/scripts/state-write.sh` directly from a scratch directory
  for testing — its `PROJECT_ROOT` self-resolves from `BASH_SOURCE` and will target the REAL
  `specs/state.json`. Always invoke a fixture-rooted copy, as this suite does.
- Do not add the caller-supplied `--argjson-file` PATH to `SPILL_FILES` in Phase 2 — that would
  make `cleanup()`'s `rm -f "${SPILL_FILES[@]}"` delete a caller's own file.
