## Key Decisions Made
- Single embedded AWK program (heredoc in the bash script) implements all three checks in one
  per-file pass, rather than three separate passes or three separate script files.
- Output protocol between AWK and the bash wrapper: fixed 7 tab-separated fields per line
  (`SEVERITY\tCHECK\tFILE\tf1\tf2\tf3\tf4`, unused trailing fields as `-`), parsed via a single
  bash `while read` loop with a `case` dispatch on `$severity`/`$check`.
- Comment/quote stripping (`gsub(/"[^"]*"/, "", clean); sub(/\/\/.*/, "", clean)`) is computed
  once per line and reused by all three checks, not just check 2's bracket matcher.
- Check 1 only evaluates the single line following a heading (after skipping the documented skip
  list); it resets on every new heading regardless of prior awaiting state, so nested headings
  with no intervening body are handled correctly.
