## What NOT to Try

- Do not combine a `kill -0` liveness check and a `pgrep -f`/`ps | grep` probe in one Bash
  command, even for a one-shot diagnostic — `validate-bounded-waiter.sh` refuses it.
- Do not stage a file via `git-commit-phase.sh`/`git-commit-scoped.sh` while it carries an
  unrelated foreign uncommitted hunk you want to leave untouched — `git commit -- <pathspec>`
  re-reads the working tree at commit time regardless of prior staging. Isolate by temporarily
  reverting the foreign hunk's own lines, commit, then restore them (as done for
  `index-entries.json` in Phase 2).
- Do not run `generate-context-line-counts.sh --write` for this task's `line_count` fix — it
  rewrites every entry in every extension. Edit the one entry surgically.
