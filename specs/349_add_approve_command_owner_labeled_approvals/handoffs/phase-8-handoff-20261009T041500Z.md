## Key Decisions Made

- **Real bug found and fixed**: `approve-classify.sh`'s diff parser skipped `---`/`+++`-shaped
  lines ANYWHERE in the diff body as file headers. A removed/added Lean line-comment whose
  content starts with `--` collides with this shape (a removed `-- note` line renders as the
  diff line `--- note`). Fixed by tracking whether the first `@@` hunk marker has been seen and
  only treating `---`/`+++`-shaped lines as skippable BEFORE that point — matching how a real
  unified diff actually disambiguates preamble from content positionally. Verified: the
  `comment-only` fixture (which exercises exactly this collision) now correctly classifies
  `mechanical`/`INFERENCE`.
- `run-all.sh` has two discovery modes (source-store vs. deployed), auto-selected by which copy
  of `run-all.sh` itself is invoked. A suite authored only in the source store (not yet
  deployed) is invisible to the DEPLOYED copy's `--only` — this is expected at this point in the
  task (deploy is Phase 9's job), not a bug.
