## Key Decisions Made

- **The "not built: over the bar with no reason" per-slice outcome is shown at prompt 2, not as
  a post-build STEP 5 line** — see progress file deviation 4.6. Phase 1's already-committed
  `over_bar_no_reason` refusal aborts the whole `check`/`build` call (one named reason, one exit
  code, uniformly with every other refusal class), so that specific outcome can never coexist
  with other slices having already built successfully in the same invocation. The command
  blocks approval entirely on an unresolved over-bar-no-reason row instead.
- **"Verify the union" needs no fourth script entry point** — `check`'s assignment proof (run
  at prompt 2) plus the suite's own static union-check guarantee (Phase 3) together satisfy
  this without inventing a verification subcommand beyond the three the ruling fixes
  (`check`/`build`/`status`, "and no other entry point").
- **`allowed-tools` extended with Read/Write/Glob** beyond the plan task's literal wording
  (`AskUserQuestion`, git/forge CLI, the script invocation) — needed for listing in-flight
  series files (Glob/Read) and writing the durable series document (Write) at approval time.
