## What NOT to Try
- A heredoc carrying test source that itself contains `EOF` lines, inside a `<<'EOF'` Bash call: the inner line ends the outer heredoc and the remainder runs as shell. Use a unique delimiter.
- `verify-touched.sh` before the redeploy: it runs deployed copies. Run `agent-system/extensions/core/scripts/tests/run-all.sh --only <suites referencing the script>` detached with a PID waiter.
