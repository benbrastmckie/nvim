  verification criterion "the fixture registry passes `lint-gate-registry.sh <fixture>/…/gate-registry.data`

  the builder already copies via `lint/`), not the real repo's copy — running the real copy
  against the fixture's data file will spuriously fail Check A since it checks against the real
  `verify-deploy.sh`. Worth keeping in mind for Phase 6's fixture-gate proof cases.
