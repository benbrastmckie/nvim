## Overview

Authored a new durable lean4 context note, `patterns/half-line-test.md`, recording the half-line
test: given a proposed transport or index condition, name the half-line the counter is read from
and the half-line the formula is read from; if both are forward, the proposal is already decided
by one recorded mechanism per direction and needs no fresh probe. The note was grounded directly
against the originating probe files (no research report was needed), registered in the lean
extension's context index with discoverable keywords, cross-linked from three pointer surfaces,
and the deployed tree was redeployed and verified clean.
