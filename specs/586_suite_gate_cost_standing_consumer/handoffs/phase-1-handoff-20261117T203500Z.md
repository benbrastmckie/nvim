## Deviations from Plan

- **Performance fix not in the original task list**: the first implementation (per-entry
  `stat`/`du` forks plus a `readlink -f` fork per `/proc/*/cwd`/`/proc/*/fd` symlink) measured
  ~44s per invocation against the real, 1,733-entry live `/tmp` backlog (23s of that inside the
  live-reference scan alone: 604 processes, 7,186 fds) — reproducing, inside this very reaper,
  the exact "fixed per-invocation cost paid many times over" defect class this whole task exists
  to eliminate in `verify-deploy.sh`. Recorded via `issue-record.sh` (class: "performance
  regression caught before commit", severity: costly) and fixed by batching (see Key Decisions
  above) before this phase closed. A full dry-run against the real backlog now takes ~3s.
- Added a bonus `/proc/*/fd`-referenced test case beyond the plan's explicitly required
  `/proc/*/cwd` case, since the pass's own candidacy gate documentation names both mechanisms.
