## Key Decisions Made

- The toolchain-detection ladder gates everything on `package.json` presence first, per the
  design spec's own first rule ("No package.json at all -> no Node/TypeScript project is in
  scope"). A bare `tsconfig.json` with no `package.json` correctly SKIPs rather than invoking
  the config-driven `npx tsc --noEmit` fallback — the fallback only fires once a `package.json`
  is already confirmed present but declares no typecheck script.
- `npx tsc --noEmit` without `typescript` installed genuinely fails in this sandbox (npx offers
  an unrelated `tsc` package), which incidentally produced a real, naturally-occurring
  `ran_fail` demonstration in addition to the explicit one.
