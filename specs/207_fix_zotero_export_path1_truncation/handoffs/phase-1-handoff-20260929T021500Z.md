## Key Decisions Made

- Added a new sibling script `generate-zotero-page-fixtures.sh` (single `jq -n`/`range`
  invocation, no argv accumulation) rather than extending the PDF-specific
  `generate-test-fixtures.py`.
- `curl-stub.sh` now resolves its own directory via `readlink -f "${BASH_SOURCE[0]}"` (with a
  `CURL_STUB_TESTS_DIR` override) so a caller that installs it via `ln -s` (not `cp`) can still
  find the sibling generator and fixtures. The pre-existing Tier 3 tests `cp` the stub and never
  exercise the Zotero routes, so they are unaffected; the new Phase 6 test file will `ln -s` it.
- Deterministic item-type distribution: `index % ratio` (`ratio` env-controllable, default 10) —
  0 -> annotation (present in raw window, absent from csljson body: models the real short-page
  quirk), 1 -> attachment, 2 -> note (both present in csljson mistyped as CSL "document": models
  the no-op-filter quirk), else -> bibliographic journalArticle.
- Generic `-o`/`-D` handling added to the stub (not Zotero-specific) also fixes the pre-existing
  `probe_zotero_api()`/`probe_bbt_rpc()` shape gap noted in the plan.
