## Key Decisions Made

- **`deploy-headless.sh`'s inline verify step auto-runs `generate-context-line-counts.sh
  --write`** as an unavoidable side effect of getting a fresh deployed tree — this happened
  three times across Phases 3, 4, and 7 of this task (whenever a redeploy was needed for gate
  testing), each time re-dirtying `index-entries.json` with several concurrent siblings'
  corrections layered on top of mine. **Resolved every single time** by reconciling the file
  programmatically against the git-committed HEAD baseline and re-applying only this task's two
  intended entries, verified via `git diff --stat` (exactly 16 lines, 11 insertions / 5
  deletions) immediately before every commit this task made. **A future task working in this
  same shared tree should expect the identical side effect** and budget for the same
  reconciliation step — this is not specific to roadmap content, it will recur for any task that
  needs a fresh redeploy mid-cycle while siblings are also active.
- **The "zero new failures against Phase 1's baseline" bar, read literally, is not achievable
  in a heavily concurrent shared-tree cycle** — Phase 1's `check-extension-docs.sh` baseline was
  0 findings; by Phase 7 it had grown to 10-14 (never from this task). The plan's own intent
  (confirmed by its gate-8 EXPECTED/NEW framing elsewhere) is "zero NEW failures attributable to
  THIS task," which is what was actually verified and documented, not a literal unchanged raw
  count — a raw-count comparison in a shared tree conflates this task's correctness with every
  concurrent sibling's mid-flight state.
- **`run-all.sh` has no suite-selection flag yet** (`--filter`/`--only`/`--list` all absent,
  confirmed via its own `--help`) — task 366's scope, unbuilt as of this task's completion. A
  bare `run-all.sh --jobs auto` invocation alone took over 540s without finishing once, under
  concurrent sibling build load; the full `verify-deploy.sh` run that includes it (gate 8) took
  roughly 14 minutes wall-clock on its successful attempt.
