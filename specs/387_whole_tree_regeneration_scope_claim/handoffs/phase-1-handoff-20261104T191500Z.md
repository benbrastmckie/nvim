## What NOT to Try

- Do not use a terminal status (e.g. `completed`) for an aux-only fixture:
  `orchestrate-build-aux-dispatch.sh` itself refuses a terminal-status task before building the
  aux row, so you get `aux_dispatch=0` too, not the intended `dispatch=0, aux_dispatch=1`
  precondition.
- Do not use status `hold` for the same fixture in this suite's minimal state shape: the fixture
  state lacks whatever `orchestrate-triage-classify.sh` needs to route a raw `hold` status to its
  dedicated bucketing arm, so the task is classified to an ordinary phase and dispatches anyway.
- Do not check single-line stdout shape via `$(printf '%s' "$LAST_STDOUT" | wc -l)` — command
  substitution already stripped the trailing newline when `LAST_STDOUT` was captured, so this
  always under-counts by one line.
